# Python for Cybersecurity

A collection of Python learning scripts for introductory cybersecurity and networking labs.

## Repository contents

| File | Topic |
| --- | --- |
| `01_Hello_Hacker.py` | Introductory Python exercise |
| `chat_client.py` | Client-side chat example |
| `chat_server.py` | Server-side chat example |
| `network.py` | Networking exercise |
| `netscan.py` | Network scanning exercise |

## Getting started

Install Python 3, clone this repository, and inspect each script and its imports before running it. Start with `python 01_Hello_Hacker.py`. Use a local virtual environment if additional dependencies are needed.

## Responsible use

Use networking and scanning exercises only on systems you own or have explicit authorization to test. Keep exercises within an isolated classroom lab; do not expose experimental chat services to the public internet.
